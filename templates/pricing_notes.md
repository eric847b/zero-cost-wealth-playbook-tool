# Pricing Notes — Zero Fixed Cost Packaging

## What you can charge (examples, adjust to market)
| Offer | Price range | Delivery |
|-------|-------------|----------|
| Template pack only | $29–79 one-time | ZIP of this repo + short Loom |
| Setup session | $99–199 | 45–60 min call + customized ledger |
| Monthly review | $49–99 / mo | client runs tools; you comment on export_report.md |
| Full playbook rewrite for niche | $299–799 | customized PLAYBOOK.md + templates |

## Delivery method (all free)
1. GitHub repo or simple ZIP download.
2. Email the Markdown / PDF report.
3. Video walkthrough with free Loom or OBS + YouTube unlisted.
4. No Stripe subscription required for the first sales — invoice via Wave or bank transfer.

## What not to do
- Do not add paid SaaS dependencies.
- Do not promise automated bank sync (that requires paid APIs).
- Keep the core CLI + CSV + Markdown export as the product surface.

## Upsell path
After 2–3 successful client deliveries, package a niche version (e.g. “Creator Cashflow Pack”) and list it on a free Gumroad / Lemon Squeezy free tier or GitHub Sponsors.
