## Product name
**Zero-Cost Client Cashflow Pack**

## One-liner
A portable wealth tracker + playbook your client unzips and runs offline — no subscriptions, no bank APIs, no paid software.

## Who it is for
Freelancers, solopreneurs, and coaches who want a simple money system they can hand to clients without building SaaS.

## What’s in the zip
- `tracker.py` — local CSV ledger CLI
- `export.py` — Markdown report → browser Print → PDF
- `PLAYBOOK.md` — zero-cost wealth loop
- `templates/` — onboarding checklist, client playbook, pricing notes, ledger template
- Sample first-week ledger so day-0 looks real
- `README_CLIENT.md` — 3-step start

Build it yourself:
```bash
python scripts/pack_client.py
# → dist/zero-cost-client-pack.zip
```

## Three benefits (use as bullets)
1. **Zero fixed cost** — client needs only Python 3 and a spreadsheet (LibreOffice / Sheets).
2. **Hand-off in one zip** — no git, no deploy, no login wall.
3. **Weekly loop included** — log → summary → export → one experiment. Repeat.
